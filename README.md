# DSH plugin index / 对话树市场索引

A format-1 market index for DeepSeek Harness plugins by [orchivo](https://github.com/orchivo).

Add it in DSH: **插件 → 发现（Discover）→ 索引源（Index sources）** →

```
https://orchivo.github.io/dsh-plugins-index/index.json
```
